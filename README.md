# Chatbot Android App

A simple Android chatbot interface built with Kotlin and Jetpack Compose. This project focuses on building a conversational user interface while practicing fundamental Android development concepts.

## Features

* Chat interface with message bubbles
* User and chatbot message alignment
* Text input handling
* Dynamic message rendering
* Message state management
* Empty-message validation
* Custom message bubble styling
* Layout design using Jetpack Compose

## Tech Stack

* Kotlin
* Jetpack Compose
* Material 3
* Android SDK

## Concepts Practiced

* `@Composable` functions
* State management with `remember` and `mutableStateOf`
* `LazyColumn` for displaying dynamic lists
* Kotlin `data class`
* Event handling with `onClick` and `onValueChange`
* Conditional UI rendering
* Layouts using `Column`, `Row`, `Box`, and `Spacer`
* Basic input validation
* UI styling with `Modifier`

## Project Structure

The main application logic is contained in `MainActivity.kt`.

The file includes:

* `Message`: Data model representing a chat message
* `MainActivity`: Application entry point
* `MainScreen`: Main chatbot interface

## Project Goal

The goal of this project was to build a first Android chat interface while learning the fundamentals of Kotlin and Jetpack Compose.

This project represents an early step in my journey toward Android and Mobile Development.
